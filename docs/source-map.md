## Published design context

The [Battle Ready Armor public preview](https://github.com/GainSec/BattleReadyArmor-PublicPreview) defines the named architectural patterns.
Its architecture, authority, privacy, materialization, agnostic-design, and growth documents provide the public design context.
The implementation references above show the current runtime paths.

## Review a mechanism

1. Start with its entry function in the table.
2. Read the referenced policy or state owner.
3. Identify the record written by that transition.
4. Inspect its consumer in the next stage.
5. Use the [development checks](development.md) for the related regression cases.
