# Product terms

| Term | Meaning |
| --- | --- |
| Alias | A word that replaces a sensitive value. |
| Approval token | A recorded permission checked by a policy script. |
| Artifact | A file produced or collected during an engagement. |
| Boots | The BRA web server and browser interface. |
| Capture | A recorded tool result with an identifier and source information. |
| CIDR | Classless Inter-Domain Routing notation for an IP address range. |
| CWE | Common Weakness Enumeration, a classification of software weaknesses. |
| Engagement | One assessment with defined targets, rules, and outputs. |
| Evidence index | The record that connects captures to artifact files and hashes. |
| Finding | A documented issue with evidence, impact, and remediation. |
| Governance | Rules and controls that define permitted operations. |
| Head | The BRA Python runtime and SDK integration. |
| Intelligence | Recorded information used during an assessment. |
| Lead | An observation that requires more investigation. |
| Marker | A structured agent output line processed by the runner. |
| Masking | Replacement of a sensitive value with an alias. |
| NER | Named entity recognition, an optional detection method. |
| Operator | The person who defines scope and reviews approvals. |
| Policy | A rule used to permit or deny an operation. |
| Provenance | Information that connects a record to its source. |
| Rehydration | Replacement of an alias with its original value. |
| ROE | Rules of engagement. |
| Scope | The targets, activities, and limits of an engagement. |
| SDK | Software development kit. |
| Takeover lease | Temporary permission for 2x4 engagement control. |
| 2x4 | An optional assistant connected through the Boots control API. |
